# Satellite Anomaly Detector

A static web demo of the finished pipeline lives in [`app/`](app/README.md).

The goal here is to train a conventional anomaly detection model and finetune a 3B-parameter LLM in order to detect satellite system abnormalities and deliver a report for mission ops teams. The models will be trained using the [OPSSAT-AD](https://zenodo.org/records/12588359) dataset.
